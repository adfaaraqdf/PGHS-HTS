# 팀 배정표

실제 팀원이 역할을 선택한 뒤 직접 채운다. 이름이나 GitHub 아이디를 추측하지 않는다.

| 이름 | GitHub 아이디 | 역할 | 첫 번째 담당 Issue | 보조 역할 | 작업 가능 시간 | 현재 상태 |
|---|---|---|---|---|---|---|
| `<이름>` | `<GitHub ID>` | 팀장·통합 | `<#Issue>` | `<보조 역할>` | `<요일/시간>` | 배정 전 |
| `<이름>` | `<GitHub ID>` | ETF | `<#Issue>` | `<보조 역할>` | `<요일/시간>` | 배정 전 |
| `<이름>` | `<GitHub ID>` | 랭킹 | `<#Issue>` | `<보조 역할>` | `<요일/시간>` | 배정 전 |
| `<이름>` | `<GitHub ID>` | 관리자·시장 운영 | `<#Issue>` | `<보조 역할>` | `<요일/시간>` | 배정 전 |
| `<이름>` | `<GitHub ID>` | 테스트·CI·QA | `<#Issue>` | `<보조 역할>` | `<요일/시간>` | 배정 전 |

상태 예시: `배정 전`, `진행 중`, `리뷰 대기`, `blocker`, `완료`.
